# Frontend

React + Vite client for the Campus Resource Booking System.

## Start

```bash
npm install
npm run dev
```

Default URL: `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```

## API Endpoint

The frontend uses `VITE_API_URL` when provided. If missing, in development it falls back to:

`http://127.0.0.1:5000/api`

For full project setup (backend env, seed data, and demo credentials), see the root README at `../README.md`.
